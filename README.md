# İstanbullu Psikoteknik

Hatay / Defne için resmi onaylı psikoteknik değerlendirme merkezi web sitesi.

**Canlı geliştirme:** Next.js (App Router), TypeScript, Tailwind CSS.

## Yerel çalıştırma

```bash
npm install
npm run dev
```

- Masaüstü: [http://localhost:3000](http://localhost:3000)
- Telefon (aynı Wi‑Fi): `http://<bilgisayar-ip>:3000`
